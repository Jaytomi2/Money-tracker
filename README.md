# Money Tracker

A clean, responsive, and lightweight Money Tracker web application built with vanilla HTML, CSS, and JavaScript.

## Features

- **Add Transactions**: Track income and expense items with name, amount, and category type.
- **Transaction Overview**: Real-time totals for Current Balance, Total Income, and Total Expenses.
- **Edit & Delete**: Easily update transaction details or remove transactions (with confirmation prompts).
- **Instant Search & Filter**: Search transactions by keyword in real time, or filter by Income / Expense tabs.
- **Top Counter**: Quick view of total transaction count right in the header.
- **Persistent Storage**: All data is stored in the browser using `localStorage`—no backend, database, or login needed.
- **Mobile Responsive**: Designed mobile-first for smooth usability on phones, tablets, and desktops.

## Tech Stack

- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom properties, responsive flexbox and grid layouts.
- **JavaScript (ES6+)**: Vanilla DOM manipulation, `localStorage` API, and internationalization formatting (`Intl.NumberFormat`).

## Getting Started

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.
